# Processed Data Directory

This directory follows the layout used for processed TerraCon data. The complete processed recordings and participant-level labels are distributed through the anonymous dataset page, not this GitHub source repository.

Dataset: <https://anonymous-hf.com/a/j33l8tgy4q7c/>

Participant-level `sub_XXX/data/` and `sub_XXX/labels/` directories belong to the dataset layout. The directories in this source repository are structural placeholders and do not contain the complete processed data.
