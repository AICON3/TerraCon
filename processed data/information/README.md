# Dataset Information

This directory contains reference materials for interpreting the TerraCon dataset.

- `equipment_information.xlsx`: equipment information.
- `subject_information.xlsx`: participant information.
- `scence_pics/`: scene images used by the dataset.

These files are included in the GitHub repository. The full raw recordings and processed participant-level data are distributed separately through the dataset repository: <https://huggingface.co/datasets/AICON3/TerraCon>.
