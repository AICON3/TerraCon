# Dataset Information

This directory contains reference workbooks for interpreting the TerraCon dataset.

## Information workbooks

- `equipment_information.xlsx`: equipment information.
- `subject_information.xlsx`: participant information.

Scene images are not included in this public repository because they may contain identifying or sensitive information. If scene images are required for a research workflow, use an appropriately reviewed and authorized dataset distribution.

The complete raw recordings and processed participant-level data are distributed separately through the dataset repository: <https://huggingface.co/datasets/AICON3/TerraCon>.
